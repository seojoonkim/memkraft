# MemKraft 3.8.0 Ambient Context Plan

## Goal
Ship one additive minor release from the unreleased 3.7.0 `origin/main` baseline. MemKraft records and selectively compiles context; Hermes remains the sole execution, approval, and permission authority.

## Feature 1: TTL Current Focus
- Add append-only focus records with explicit timezone-aware `now` and bounded TTL.
- Add `focus_budget=0` as an opt-in `compile_context` keyword.
- Preserve byte-identical compiler output and `usage_id` when unused.
- Include at most three active focus records, with deterministic ordering and hard token limits.
- Never gate, dispatch, approve, edit skills, or own scheduling.

## Feature 2: Decision Authority Provenance
- Add a separate append-only, inert authority-provenance ledger; do not alter existing decision records or decision ranking.
- Store a canonical authority ID, source reference, version, scopes, issue time, optional expiry, and append-only revocation events.
- Keep `authority_verified` derived and always false; MemKraft does not verify or enforce external authority.
- Add `authority_budget=0` as an opt-in `compile_context` keyword with exact legacy output when unused.
- Preserve legacy decision files and writes byte-for-byte by keeping this feature isolated from the decision store.

## TDD Sequence
1. Write RED focus storage and compiler integration tests.
2. Implement the smallest focus storage/mixin/compiler changes and make focused tests GREEN.
3. Write RED decision-authority tests.
4. Implement optional authority provenance and make focused tests GREEN.
5. Run adjacent and full regression suites.
6. Update release metadata atomically for 3.8.0, build wheel/sdist, and smoke a fresh wheel.
7. Independently review security, compatibility, packaging, and Hermes integration.
8. Publish only after all gates pass; verify PyPI/GitHub and fresh public installation.

## Verification Criteria
- Existing compiler output remains byte-identical when both new features are unused.
- Malformed/expired focus records never enter compiled context.
- Authority claims cannot become approvals or verified authority inside MemKraft.
- Python 3.9-compatible annotations and parsing.
- Full Python tests, Go conformance, release benchmarks, lineage audit, build/twine, fresh-wheel smoke, and Hermes provider smoke all pass.
