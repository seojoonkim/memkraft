## MemKraft 4.1.1

This release adds the verified WikiSkill experience pipeline.

- Persists raw experiences with provenance and verification metadata.
- Promotes only verified experiences into Wiki knowledge.
- Compiles and lists reusable Skills only while their sources remain verified.
- Provides runtime-neutral integration surfaces for Hermes and OpenClaw adapters.

The pipeline is deterministic and does not perform automatic LLM extraction or
unverified evidence adjudication.
