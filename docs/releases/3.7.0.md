## MemKraft 3.7.0

MemKraft 3.7.0 adds an additive typed Memory Graph projection for accountable memory operations.

### Highlights

- Artifact, Claim, typed Relation, and lifecycle records are stored in a separate append-only projection.
- Append and strict replay use the same normalized canonical payload and digest.
- CAS and idempotent operation handling prevent accidental duplicate mutation.
- Valid-time and transaction-time filtering preserve historical reads.
- Exact-first retrieval returns deterministic provenance paths and excludes inactive traversal seeds by default.
- Contradiction and supersession lifecycle transitions are guarded by blast-radius and schema/provenance validation.
- Advisory locking and rollback-safe writes fail closed on corruption, short writes, forged correction references, and inconsistent operation timestamps.
- `graph-replay` and `graph-recall` provide read-only CLI inspection.

### Compatibility

This release is additive. Existing MemKraft public APIs, legacy `graph.db`, correction authority, and stored data remain unchanged. The new projection is lazy-created under `.memkraft/memory_graph.jsonl`.
