## MemKraft 3.6.0

MemKraft 3.6.0 introduces opt-in Correction Learning without changing existing memory-store behavior for callers that do not use it.

### Governed correction policies

- Preserves user and assistant evidence as separate roles.
- Captures and revises scoped policies through an append-only, fail-closed correction log.
- Uses the Improvement Ledger as the sole promotion, activation, and rollback authority; correction evaluations gate only scope widening.
- Keeps private-profile content private and exposes only bounded policy projections.

### Bounded application and outcomes

- Selects only applicable active policies with deterministic task, project, task-class, and global precedence.
- Enforces a deterministic token-estimate budget and reports whole-item omissions and conflicts.
- Records exactly `complied`, `violated`, and `not_applicable` outcomes and links user-correction cases to the existing Evaluation Corpus.
- Supports rollback without deleting the audit history.

### Verified release gate

The frozen five-case Correction Learning gate reports fidelity 1.0, zero control interference, recorded compliance 1.0 from persisted caller-recorded outcomes, deterministic output, and warm p95 below the 50 ms threshold on the recorded host. It verifies outcome persistence, not behavioral recurrence prevention. Two-host evidence remains explicitly `not_ready` and is not claimed by this release.

See `docs/bench/results/3.6.0-corrections-gate.json` for the machine-readable result.
