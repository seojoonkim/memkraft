## MemKraft 3.6.0

MemKraft 3.6.0 introduces opt-in Correction Learning without changing existing memory-store behavior for callers that do not use it.

### Governed correction policies

- Preserves user and assistant evidence as separate roles.
- Captures and revises scoped policies through an append-only, fail-closed lifecycle.
- Requires fresh evaluation and authority evidence for activation and scope widening.
- Keeps private-profile content private and exposes only bounded policy projections.

### Bounded application and outcomes

- Selects only applicable active policies with deterministic task, project, task-class, and global precedence.
- Enforces item and character budgets and reports omissions and conflicts.
- Records prevented, recurred, unknown, and not-applicable outcomes and links user-correction cases to the existing Evaluation Corpus.
- Supports rollback without deleting the audit history.

### Verified release gate

The frozen five-case Correction Learning gate reports fidelity 1.0, zero control interference, recurrence prevention 1.0 from persisted outcomes, deterministic output, and warm p95 below the 50 ms threshold on the recorded host. Cross-host latency evidence remains explicitly `not_ready` and is not claimed by this release.

See `docs/bench/results/3.6.0-corrections-gate.json` for the machine-readable result.
