## MemKraft 4.2.0

This release adds an owner ledger so agents check the owner's past directives
before asking again, and queue only decisions that genuinely need the owner.

- Owner sayings: the owner's directives are stored verbatim with scope, tags,
  and source. Search is deterministic, needs no LLM, and handles Korean verb
  conjugation without an analyzer.
- Decision queue: only irreversible categories (money, delete, publish,
  account, credential, legal, external_contract) are queued. Reversible work
  returns `action: proceed`. Open items are deduplicated and summarized in a
  batched digest.
- Hermes provider: exposes five `owner_*` tools, recalls up to two matching
  sayings verbatim in prefetch, and shares one owner directory across profiles
  (`MEMKRAFT_OWNER_DIR`, default `<hermes root>/memkraft-owner`).
