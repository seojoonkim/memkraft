## MemKraft 4.3.0

Curated work lessons and Korean-aware, quote-safe ReasoningBank recall. No migration required.

- Curated work lessons: `lesson_add(id, rule=..., triggers=..., examples=...)` and
  `memkraft lesson add|list|check` record hand-written work rules such as
  "the same approach failed twice: switch approach". Auto-captured lessons only
  describe tool errors; curated lessons cover workflow mistakes. They are matched
  on their trigger words, rank above auto-captured tool detours, and are shown to
  Hermes as `Work rule` lines (still quoted as untrusted data).
- Recall regression check: `lesson_check()` / `memkraft lesson check` replays the
  real requests stored with each lesson and exits 1 when a lesson would not be
  recalled, so a rule that silently stops surfacing is caught.
- Quote-safe recall: ReasoningBank recall ignores host-quoted context
  (`[Replying to: ...]`, `<memory-context>` blocks) and keys on the user's own words.
  Replying to an old report no longer recalls lessons for the quoted report.
- Korean-aware matching: recall also matches Korean stems without trailing particles
  and endings, so "크기를" matches "크기". Stored pattern signatures are unchanged.

### Verification

- New `tests/test_curated_lessons.py` (10 tests); ReasoningBank and development-experience
  suites: 166 passed.
- A/B on a copy of one real Hermes ReasoningBank store (Korean chat, 182 trajectories)
  with the same four rules stored through each version's API and seven real requests:
  correct rule ranked first for 2/6 requests before, 6/6 after; a reply quoting an
  old health report recalled 3 unrelated lessons for that report before, 0 after.
  Recall stayed under 5 ms per query. Local single-store measurement.
